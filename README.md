# many-games

A collection of small, self-contained browser games. Each game is a single HTML file —
open it directly, no build step and no server.

## Games

| Game | File | About |
| --- | --- | --- |
| 🍞 **BREAD CLICKER** | [`bread-clicker.html`](bread-clicker.html) | A modern idle/clicker game. Click the loaf, build 16 kinds of tower, level them up, prestige them, and chase 156 upgrades and 59 achievements. Progress saves to local storage. |
